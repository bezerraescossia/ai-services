## Dependencies & Execution Order

- Phase 1 (Setup) must fully complete before Phase 2 — dependencies must be installed and DVC initialized before any test can import the new libraries or shell out to `dvc`.
- Phase 2 (Foundational) must complete before Phase 3 or Phase 4 — both stories' pipelines are built from T014-T018, including `corpus_version` computation itself.
- Phase 3 (US1) and Phase 4 (US2) both depend only on Phase 2, not on each other — Phase 3 delivers a working, queryable pipeline with correct `corpus_version` tagging but no DVC persistence or idempotency short-circuit; Phase 4 adds persistence/idempotency on top. They are sequenced US1-then-US2 to match `spec.md`'s own story order and because T027 modifies `pipeline.py`, which T020 must have created first.
- Final Phase depends on Phase 3 and Phase 4 both being complete.
- Backward-loop note: if T019/T022 reveal the chunking or retry behavior from Phase 2 doesn't hold up end-to-end (e.g. real Wikipedia responses don't match the mocked fixture shape), loop back to T014/T015 rather than patching around it in `pipeline.py`. If T023's real-content spot-check finds awkward splits, loop back to T015 and re-run T022 before proceeding to Phase 4.
